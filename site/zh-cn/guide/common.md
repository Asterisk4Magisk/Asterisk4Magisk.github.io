# 通用功能

## 分应用代理 {#per-app-proxy}

决定哪些应用的流量进入代理。

- AsteriskNG：底部 **应用** 页。
- AsteriskMETA / AsteriskBOX：**设置 → 常规 → 分应用代理**。

三种 **代理模式**：

| 模式 | 效果 |
| --- | --- |
| **全应用模式** | 所有应用均使用代理 |
| **白名单模式** | 仅名单中的应用使用代理，其他应用直连 |
| **黑名单模式** | 仅名单中的应用不使用代理，其他应用均使用代理 |

常用操作（位于页面的更多操作菜单）：

- **显示系统应用**：列表中包含系统应用。
- **扫描中国应用**：自动识别并勾选中国应用，常配合黑名单模式让这些应用直连。全应用模式下会跳过扫描。
- **反选** / **清空**：快速调整名单。
- **从剪贴板导入** / **导出到剪贴板**：在设备或应用之间迁移名单；导入时可选择 **合并导入** 或 **替换现有**。
- 下拉列表可刷新已安装应用。

ROOT 模式开启 FakeDNS / FakeIP 时的限制见 [常见问题](./faq#fakedns-app-list)。

## 资源管理 {#resources}

**设置 → 常规 → 资源管理** 用于管理代理核心与规则资源文件（GeoIP、GeoSite、规则集等）。

- 每个文件显示 **已就绪** / **缺失** 状态、大小与更新时间。
- **更新资源文件**：从 **更新来源** 下载最新版本；可开启 **资源自动更新**，联网时按设定周期（小时）更新。
- 点击文件可 **替换**（从本地选择）、**恢复** 为内置文件，或删除自定义文件。
- **添加自定义资源文件**：指定文件名与下载 URL。
- 标注 **仅用于 ROOT 运行模式** 的文件只在 ROOT 模式下使用。
- 服务运行中时，资源文件更新成功后会自动应用到运行中的服务。

可选的更新来源：

| 应用 | 内置来源 |
| --- | --- |
| AsteriskNG | Loyalsoldier、V2Fly、Chocolate4U、RunetFreedom（GitHub），或自定义 geodata 地址 |
| AsteriskMETA | MetaCubeX（GitHub），或自定义地址 |
| AsteriskBOX | 默认（GitHub），或自定义地址；另可从 sing-geoip / sing-geosite 目录批量添加规则集 |

### 自定义核心

资源管理中的 **核心文件** 可以替换为自行上传的核心可执行文件，VPN 与 ROOT 模式共用同一个核心。恢复为内置文件即可回到应用自带的核心。

::: warning
部分功能依赖内置核心，例如 AsteriskMETA 的 [自动切换](./meta#auto-switch)。上传的自定义核心可能与当前应用版本不兼容，出现问题时请先恢复内置核心。
:::

AsteriskMETA 与 AsteriskBOX 在 ROOT 模式下使用自定义核心时，导入、保存与启动前不再用内置核心校验配置，以免拒绝只有自定义核心才支持的协议或字段；配置错误由自定义核心在启动时报告。VPN Service 模式仍会完整校验。

## 开机自启 {#start-on-boot}

在 **设置 → 代理设置（当前模式）** 中开启 **开机自启**：

- **VPN Service**：开机后自动启动 VPN 服务；应用更新后也会恢复更新前的服务状态。需要事先授予 VPN 权限。
- **ROOT 模式**：生成 `service.d` 启动脚本，由 ROOT 方案在开机时拉起服务。

部分厂商系统需要额外允许应用 **自启动 / 后台运行**，否则开机自启可能不生效。

## 通知与快捷设置磁贴

- **显示统计数据**（设置 → 代理设置（当前模式））：在通知和状态栏中显示当前速度与累计流量。
- **快捷设置磁贴**：在下拉快捷设置的编辑界面中添加本应用的磁贴，点击即可启动 / 停止代理；长按打开应用。若尚未授予 VPN 权限，按提示授权后再次点击即可启动。磁贴状态会随运行模式、运行状态与语言实时更新，ROOT 模式下由服务控制触发的启停也会同步显示。

## 外观与语言

- **主题**：跟随系统、浅色或深色；**强调色** 可选系统默认（动态取色）或预设颜色。
- **语言**：AsteriskNG 支持简体中文、English、Русский、Tiếng Việt；AsteriskMETA 与 AsteriskBOX 支持简体中文与 English。
- **自动隐藏导航栏**（AsteriskMETA / AsteriskBOX）：上滑页面时自动隐藏底部导航栏。
- **网络活动图表**（AsteriskMETA / AsteriskBOX）：首页网络活动卡片的样式，可选 **点阵波形**（默认）或 **双折线**。
- AsteriskMETA / AsteriskBOX 的设置页顶部支持搜索设置项。

## 隐私 {#privacy}

| 设置项 | 作用 |
| --- | --- |
| **隐藏最近任务** | 应用不在最近任务列表中显示 |
| **允许截屏** | 关闭后禁止对本应用截屏与录屏 |
| **隐藏桌面图标** | 从桌面移除图标；可通过拨号暗码或长按快捷设置磁贴打开应用 |

隐藏桌面图标后，在系统拨号界面输入以下暗码即可打开应用：

| 应用 | 拨号暗码 |
| --- | --- |
| AsteriskNG | `*#*#260517#*#*` |
| AsteriskMETA | `*#*#260608#*#*` |
| AsteriskBOX | `*#*#260728#*#*` |

部分厂商系统需要允许应用 **自启动 / 后台运行** 才能响应拨号暗码。开启前请先确认自己能通过上述方式打开应用。

AsteriskNG 另有 **删除确认**：删除节点、路由、分组、资源时需二次确认。

## 日志 {#logs}

**设置 → 日志** 中可查看：

- **核心日志**：代理核心的输出，等级由 **日志等级** 控制。
- **访问日志**（AsteriskNG）：开启 **记录访问日志** 后记录每条连接的去向。
- **Logcat**：应用自身的系统日志，排查启动问题时最有用。

日志页支持实时刷新、暂停、复制与 **导出日志**。反馈问题时请附上导出的日志，并注意先删除其中的订阅地址、服务器地址等敏感信息。

## 备份与还原 {#backup}

**设置 → 备份与还原**：

- **备份用户数据**：将设置、节点 / 配置、订阅分组、路由规则、分应用名单等导出到一个备份文件。
- **还原用户数据**：从备份文件还原。还原前会显示备份的创建时间、版本与条目数量。

::: warning 还原会覆盖当前数据
还原会覆盖当前的全部用户数据，并且：当前代理会被停止，ROOT 开机脚本会被禁用，运行模式会切换回 VPN Service。还原后请重新检查运行模式与开机自启。
:::

备份文件包含订阅地址与节点凭据，请妥善保管，不要公开分享。
