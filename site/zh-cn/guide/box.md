# AsteriskBOX

AsteriskBOX 是基于 **sing-box** 核心的客户端。它把 sing-box 配置拆成若干可视化模块——**出站分组**、**选择器**、**端点**、**DNS**、**路由**——分别管理，最后由应用生成完整的 sing-box 配置。你可以完全通过界面配置，也可以在关键位置直接编辑 JSON，或用覆写脚本做最后的调整。

底部导航共四页：**首页**、**代理**、**分组** 和 **设置**。

## 配置是如何组成的

| 模块 | 对应 sing-box 配置 | 在哪里管理 |
| --- | --- | --- |
| 分组与出站（节点） | `outbounds` | 底部 **分组** 页、**设置 → 出站管理** |
| 选择器（Selector / URLTest） | `outbounds` 中的 selector / urltest | **设置 → 选择器管理**；在 **代理** 页切换 |
| 端点（WireGuard、Tailscale 等） | `endpoints` | **设置 → 端点管理** |
| DNS 服务器与规则 | `dns` | **设置 → DNS 管理** |
| 路由规则 | `route` | **设置 → 路由管理** |
| 覆写脚本（可选） | 对生成结果做最后修改 | **设置 → 高级设置 → 覆写脚本** |

- 每个出站分组自带一个托管选择器，成员随分组自动更新；自定义选择器可以自由组合多个分组的出站。
- 路由规则和 DNS 规则可以引用出站、选择器或端点。
- 生成的完整配置可在 **设置 → 工具 → 配置预览** 中查看。

## 首页

- **启动服务** / **停止服务**、服务状态与本次运行时长，以及今日流量与实时网速。
- **代理模式**：**规则** / **全局** / **直连**，通过路由规则中的 `clash_mode` 条件实现，见 [sing-box 配置 · 路由规则的顺序](./core-singbox#route-order)。
- 与 AsteriskMETA 相同的 **流量**、**连接**、**资源**、**网络** 监控卡片，详见 [AsteriskMETA · 首页](./meta#home)。

## 分组与出站

### 添加分组

在 **分组** 页点击 **添加分组**：

- **手动填写**：填写远程订阅 URL，或留空订阅地址新建 **本地分组**；
- **文件**：导入本地的 sing-box JSON、Mihomo YAML 或节点链接文件；
- **二维码**：扫描订阅链接二维码并立即同步。

| 字段 | 说明 |
| --- | --- |
| **名称** | 留空则首次同步后自动命名 |
| **订阅地址（可选）** | 留空即为本地分组。使用 HTTP 时会提示改用 HTTPS |
| **更新间隔（小时，可选）** | 自动更新周期 |
| **通过当前运行的代理更新** | 经由代理下载订阅 |
| **User-Agent** | sing-box、Clash Meta、v2rayNG 或自定义 |
| **HWID**、**Mihomo Age 私钥** | 设备标识上报与 Age 解密 |
| **严格导入** | 订阅中任一条目无效时，保留现有节点不更新 |
| **前置代理** | 为整个分组的出站指定前置（中转）出站 |

**更新全部分组订阅** 会依次下载、解密、解析、校验并保存每个订阅，完成后显示导入 / 跳过 / 重复数量与失败原因。分组卡片显示订阅的已用流量、总量与到期时间。

分组卡片菜单中的 **分享** 可以显示 **订阅二维码**、**复制订阅链接**、复制组内全部出站的分享链接，或 **导出链接到文件**。没有标准分享链接的出站会被跳过；分组同步期间无法复制或导出。

### 出站

在分组中可以 **导入出站**（**扫描二维码**、**从文件导入**、剪贴板）或 **手动添加**。支持的出站协议：

SOCKS、HTTP、NaiveProxy、Shadowsocks、VMess、Trojan、Hysteria、Hysteria 2、VLESS、ShadowTLS、TUIC、AnyTLS、Snell、SSH；以及通过 [协议插件](#plugins) 支持的 Mieru、ShadowQUIC、Juicity。

出站编辑器按 sing-box 的结构分为若干区块：**服务器**、**协议**、**TLS**（含 uTLS 与 Reality）、**V2Ray 传输层**（HTTP、WebSocket、QUIC、gRPC、HTTPUpgrade）、**多路复用**、**QUIC** 和 **拨号**（绑定接口、域名解析器、超时与网络策略）。

出站列表的菜单提供 **PING 当前分组**、布局与排序（手动顺序 / 别名 / 协议 / PING 延迟）、搜索、复制所有节点 URL、删除重复节点等操作。出站可 **复制 URL**、**生成二维码** 或 **复制 JSON**。

服务运行中手动修改分组或出站后，应用会提示 **修改尚未生效**，点击 **立即应用** 即可。订阅更新改变了出站、或资源文件更新成功时，会自动应用到运行中的服务：VPN Service 模式就地热重载，ROOT 模式重启服务。

## 代理

**代理** 页列出所有选择器，点击节点即可切换，需要先在首页启动服务。使用顶栏标签页布局且选择器较多时，点击 **展开代理组** 可在面板中列出全部选择器并快速跳转。

## 设置 · 常规

### 出站管理 / 选择器管理

- **出站管理**：集中导入、添加、编辑各分组中的出站。
- **选择器管理**：创建与编辑 **Selector**（手动选择）和 **URLTest**（自动选择）。

URLTest 的选项：

| 选项 | 说明 |
| --- | --- |
| **选择方式** | **延迟优选**（优先低延迟节点）或 **故障转移**（按顺序选择可用节点） |
| **最大可接受延迟** | 故障转移时优先选择延迟低于该值的节点；留空或 0 表示不限 |
| **测试地址** / **测试间隔** | 留空使用默认值（间隔 3m） |
| **容差（ms）** | 延迟差超过该值才切换，默认 50ms |
| **空闲超时** | 空闲后暂停测试，默认 30m |

另可设置切换出站时是否断开已有连接。

::: details 核心实现
Selector 与 URLTest 分别对应 sing-box 的 `selector` 与 `urltest` 出站。URLTest 按 **测试间隔** 向 **测试地址** 发起请求，仅当更快节点的延迟优势超过 **容差** 时才切换，避免频繁跳动；超过 **空闲超时** 没有流量时暂停测试以节省电量。**故障转移** 与 **最大可接受延迟** 是内置核心提供的扩展选项。
:::

### 端点管理

**端点** 是 sing-box 中的 VPN 隧道类出站：

| 端点类型 | 用途 |
| --- | --- |
| **WireGuard** | 三层 WireGuard 隧道 |
| **Tailscale** | 将本设备接入 Tailscale 网络 |
| **OpenVPN Client** | 使用 OpenVPN 客户端配置连接 |
| **OpenConnect** | 连接兼容 AnyConnect 的 VPN 服务器 |
| **MASQUE Client** | 通过 HTTP 建立 IP 代理连接（CONNECT-IP） |

可以直接导入 sing-box 端点 JSON，或 WireGuard、OpenVPN、OpenConnect 的配置文件。出于安全考虑，配置中不安全或引用外部文件的指令会被拒绝。

### DNS 管理

**DNS 管理** 对应 sing-box 的 `dns` 配置：

- **DNS 服务器**：支持 UDP / TCP、TLS、HTTPS、HTTP/3、QUIC、本地解析器、DHCP、Hosts、mDNS、Resolved、分组，以及 Tailscale / OpenVPN / OpenConnect 端点提供的 DNS。
- **默认 DNS 服务器**：处理普通 DNS 查询。
- **出站域名解析器**：连接前用于解析代理服务器与端点的域名。
- **DNS 规则**：按域名、查询类型、响应内容等条件匹配，动作包括 **路由**、**拒绝**、**预定义响应**、**评估** 与 **响应**。
- **FakeIP** 及 **持久化 FakeIP 映射**；缓存选项包括 LRU 缓存容量、**乐观 DNS 缓存**、**持久化 DNS 缓存** 等。

::: details 核心实现
DNS 规则按顺序匹配，首条命中的规则决定处理方式，对应 sing-box DNS 规则的 `action` 字段：**路由** 把查询交给指定服务器，**拒绝** 直接拒绝查询，**预定义响应** 返回你填写的记录。未命中任何规则的查询交给 **默认 DNS 服务器**。

代理服务器自身的域名由 **出站域名解析器** 解析（对应 `route.default_domain_resolver`），这样连接代理前不会依赖代理本身的 DNS。
:::

### 路由管理

**路由管理** 对应 sing-box 的 `route` 配置：

- **路由规则**：动作为 **路由到出站** 或 **拒绝连接**；没有规则匹配时使用默认出站。
- **路由设置**：自动检测默认出站接口、默认网络策略与回退网络、查找连接所属进程等。
- 规则集来自 **资源管理** 中的 `.srs` / `.json` 文件。

### 协议嗅探

在路由规则前插入 sing-box 嗅探动作。可启用的嗅探器：HTTP、TLS、QUIC（可提取目标域名），以及 DNS、BitTorrent、DTLS、NTP、RDP、SSH、STUN（增强基于协议的路由）。**嗅探超时** 默认 300ms。

::: details 核心实现
新版 sing-box 不再在入站上配置嗅探，而是使用路由规则动作 `sniff`。应用把它放在 `route.rules` 的最前面，嗅探出的域名与协议会用于后续规则的 `domain`、`protocol` 等条件匹配。
:::

### 资源管理

除 [通用功能](./common#resources) 中的功能外，AsteriskBOX 还支持：

- 从 sing-geoip / sing-geosite 的目录中搜索并批量添加规则集；
- 添加自定义 `.srs`、`.json` 规则集或 `.hosts` 文件（URL 可选，也可只用本地文件）；
- 内置 **JSON 规则集** 编辑器（保存时会校验）与 **Hosts** 编辑器。

### 连接测试

测试链接、超时与并发等；可选择在 TCP / TLS 握手完成后再开始计时，排除握手耗时。

## 设置 · 工具

- **配置预览**：查看应用生成的完整 sing-box 配置，便于核对或排查。
- **网络质量测试**：使用 Apple networkQuality 协议测试经由所选出站的上下行带宽、响应度（RPM）与空闲延迟。

## 设置 · 高级

- **插件**：管理协议插件，见下文。
- **覆写脚本**：在生成配置后用 JavaScript 进一步修改。调试时可查看输出 JSON、Console 与警告，并复制报告。脚本接口、标签命名与示例见 [sing-box 配置](./core-singbox)。
- **广播控制**、IPv6 与 **IPv6 优先**。

## 协议插件 {#plugins}

部分协议以独立的插件 APK 分发，安装后由 sing-box 核心作为子进程运行。**设置 → 高级设置 → 插件** 列出各插件的安装状态，未安装时点击即可前往下载页：

| 插件 | 用途 |
| --- | --- |
| Mieru | 提供 Mieru 出站，支持 `mierus://` 分享链接 |
| ShadowQUIC | 提供 ShadowQUIC 出站，支持 `sq://` 分享链接 |
| Juicity | 提供 Juicity 出站，支持 `juicity://` 分享链接 |
| Hysteria2（可选） | 替代内置实现，不支持端口跳跃 |
| NaiveProxy（可选） | 替代内置实现，不支持 QUIC |

在 **协议实现** 中开启 **使用 Hysteria2 插件** / **使用 NaiveProxy 插件** 后，对应出站改由插件运行；关闭时使用内置实现。

::: warning
- 应用只识别由 husi、SagerNet、Exclave 或 Matsuri 签名的插件。
- 配置中使用了未安装插件的出站时，服务不会启动，并提示需要安装的插件。
- 插件不支持的选项（如 Hysteria2 的端口跳跃、NaiveProxy 的 QUIC）会直接报错，而不是被静默忽略。
:::

::: details 核心实现
插件出站在覆写脚本**之后**、核心校验之前被编译成一个本地回环的 SOCKS 出站，由插件进程负责实际连接，因此配置预览、脚本调试与校验看到的都是实际运行的配置。VPN 模式下插件自行保护其套接字以免流量回环；ROOT 模式下插件经由一个直连映射入站发起连接。
:::
