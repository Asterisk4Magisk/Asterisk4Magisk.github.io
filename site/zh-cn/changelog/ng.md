# AsteriskNG 更新日志

这里整理了 AsteriskNG 各正式版本中用户可感知的变化。完整的提交列表与安装包见 [AsteriskNG Releases](https://github.com/Asterisk4Magisk/AsteriskNG/releases)。

日期为 GitHub Releases 的发布日期（UTC）。

## 1.4.25 · 2026-11-03 {#v1-4-25}

- **新增**：订阅分组可以分享与导出——订阅二维码、复制订阅链接、复制组内全部节点链接、导出链接到文件。见 [AsteriskNG · 订阅分组](../guide/ng#订阅分组)。
- **新增**：ROOT 模式下，开机时已连接到匹配 **连接 WiFi 时停止** 的网络时，开机自启不再启动代理。见 [自动化 · Wi-Fi 控制](../guide/automation#wi-fi-控制)。
- **改进**：快捷设置磁贴实时反映运行模式、运行状态与语言变化，切换过程中保持「处理中」直到操作完成。
- **修复**：ROOT 开机配置写入与代理启停并发时可能出现的冲突。
- **其他**：加固 `:vpn` 进程边界，流量统计改在 `:service` 进程中运行。

## 1.4.24 · 2026-11-01 {#v1-4-24}

- **改进**：VPN Service 改为在独立进程中运行。
- **改进**：屏幕关闭时暂停流量统计更新，减少耗电。
- **改进**：状态栏网速文字大小更均衡。
- **修复**：asteriskd 更新到 v2.2.7，可处理厂商系统中较大的 mangle 表。
- **核心**：Xray 更新到 v26.10.31。

## 1.4.23 · 2026-10-29 {#v1-4-23}

- **改进**：状态栏网速图标显示上下行合计速度，文字更大。
- **修复**：服务控制设置保存过程中不再被中断；asteriskd 更新到 v2.2.5，bpf2socks 更新到 v1.2.2。
- **核心**：Xray 更新到 v26.10.29。

## 1.4.22 · 2026-10-28 {#v1-4-22}

- **新增**：VPN Service 模式支持开机自启，并支持系统的「始终开启的 VPN」。
- **新增**：支持导入 v2rayN 格式的分享链接，订阅解析更完善。

## 1.4.21 · 2026-10-25 {#v1-4-21}

- **新增**：状态栏显示实时下载速度。
- **改进**：ROOT 模式应用规则的速度明显加快；启动时给核心最多 15 秒就绪时间。
- **修复**：底部导航栏不再被键盘遮挡，编辑器在键盘弹出时不再跳动。
- **修复**：禁用系统 IPv6 的防护只作用于应用可访问的网络。

## 1.4.20 · 2026-10-21 {#v1-4-20}

- **修复**：开启 FakeDNS 时 AAAA 查询返回空结果，避免 IPv6 地址绕过。
- **核心**：AndroidLibXrayLite 更新到 v26.10.22，默认 DNS 改为本地解析。

## 1.4.19 · 2026-10-20 {#v1-4-19}

- **新增**：路由规则的进程条件可以直接从已安装应用中选择。
- **新增**：FakeDNS 地址池可配置（仅 IPv4）。
- **改进**：分应用代理模式增加帮助说明，对话框更易读。

## 1.4.18 · 2026-10-18 {#v1-4-18}

- **新增**：MASQUE 节点支持。
- **新增**：设置中新增 **隐私** 分区；移除 Monet 桌面图标。
- **修复**：放宽核心与辅助进程端口就绪检测。
- **核心**：Xray 更新到 v26.10.17。

## 1.4.17 · 2026-10-15 {#v1-4-17}

- **新增**：订阅分组可根据订阅标题自动命名。
- **新增**：QUIC 与 WireGuard 节点支持握手延迟测试。
- **修复**：bpf2socks 中继、热点与空闲唤醒相关问题。

## 1.4.16 · 2026-10-13 {#v1-4-16}

- **修复**：增强模块的 DNS 与 netd 相关问题；改进增强模块安装对话框。

## 1.4.15 · 2026-10-13 {#v1-4-15}

- **新增**：可在最近任务中隐藏应用。
- **新增**：集成应用列表增强与 DNS 增强（需安装增强模块）。
- **修复**：ROOT 模式下的流量通知与统计采样。
- **核心**：Xray 更新到 v26.10.10。

## 1.4.13 · 2026-10-09 {#v1-4-13}

- **修复**：订阅更新时保留节点 ID，已选节点不再丢失。
- **修复**：ROOT 模式绕过私有地址段的范围。

## 1.4.12 · 2026-10-01 {#v1-4-12}

- **修复**：ROOT 模式开启 FakeDNS 时强制使用全部应用模式。
- **修复**：订阅更新优先经本地代理，失败时回退直连。
- **核心**：Xray 更新到 v26.9.30。

## 1.4.11 · 2026-09-27 {#v1-4-11}

- **新增**：轻量的自动暂停与恢复。
- **新增**：Android 13 及以上支持锁屏 / 解锁服务控制。
- **新增**：WireGuard 节点支持远程 DNS。
- **修复**：切换语言后界面即时更新；不支持的 Android 版本上隐藏 VPN HTTP 代理选项。

## 1.4.10 · 2026-09-24 {#v1-4-10}

- **新增**：订阅分组支持拖动排序。
- **改进**：「启用本地 DNS」更名为「启用 DNS 劫持」。
- **修复**：VPN Service 使用 Xray 内置 TUN 时，路由规则的进程条件无法匹配应用。

## 1.4.9 · 2026-09-18 {#v1-4-9}

- **新增**：资源文件自动更新。
- **新增**：订阅与资源更新的广播命令。
- **新增**：分应用代理菜单中的「扫描国产应用」。
- **新增**：ROOT 启动失败诊断。
- **改进**：延迟颜色与阈值调整，失败结果显示为红色；强调色更新。

## 1.4.8 · 2026-09-13 {#v1-4-8}

- **新增**：越南语界面。
- **改进**：拖动排序在松手后才提交；键盘弹出时编辑器自动展开。

## 1.4.7 · 2026-09-05 {#v1-4-7}

## 1.4.4 · 2026-08-26 {#v1-4-4}
