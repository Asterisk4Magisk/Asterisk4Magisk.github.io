# AsteriskMETA 更新日志

这里整理了 AsteriskMETA 各正式版本中用户可感知的变化。完整的提交列表与安装包见 [AsteriskMETA Releases](https://github.com/Asterisk4Magisk/AsteriskMETA/releases)。

日期为 GitHub Releases 的发布日期（UTC）。

## 1.2.26 · 2026-11-05 {#v1-2-26}

- **新增**：Android 17 上启动时申请本地网络权限，保证局域网节点与热点共享可用。见 [快速开始](../guide/getting-started#首次连接)。
- **新增**：顶栏标签页布局下，策略组较多时可点击 **展开代理组** 在面板中快速跳转。
- **修复**：Meow 版在 TUN2SOCKS / BPF2SOCKS 模式下 DNS 劫持规则不生效的问题（托管规则改用 `IN-TYPE,SOCKS5`）。
- **改进**：增强开关与设置搜索结果使用图标强调色。
- **核心**：Meow 更新到 v0.29.0。

## 1.2.25 · 2026-11-03 {#v1-2-25}

- **新增**：首页网络活动卡片改为点阵波形，可在外观设置的 **网络活动图表** 中改回 **双折线**。
- **改进**：资源监控拆分为 CPU 与内存两张卡片，详情增加平均值、运行时长、今日流量与活动连接数。
- **新增**：开机时已连接到匹配「连接 WiFi 时停止」的网络时，开机自启不再启动代理。
- **改进**：快捷设置磁贴实时反映运行状态。
- **修复**：ROOT 模式使用自定义核心时，订阅不再因内置核心不认识的协议或字段而同步失败。见 [通用功能 · 自定义核心](../guide/common#自定义核心)。
- **修复**：ROOT 开机配置写入与代理启停并发时可能出现的冲突。

## 1.2.24 · 2026-11-01 {#v1-2-24}

- **新增**：支持 Meow 核心，以 `-meow` APK 分发。见 [AsteriskMETA · 核心版本](../guide/meta#core-editions)。
- **新增**：代理页支持 **展开列表** 布局与多列布局，可设置列数；Provider 用量顺序与配置保持一致。
- **改进**：VPN Service 运行在独立进程中，资源监控统一统计该进程。
- **改进**：屏幕关闭时暂停流量统计更新；状态栏网速图标显示合计速度。
- **修复**：离开页面后 ROOT 服务不再被停止；asteriskd 更新到 v2.2.7，bpf2socks 更新到 v1.2.2。

## 1.2.23 · 2026-10-28 {#v1-2-23}

- **新增**：VPN Service 模式支持开机自启，并支持系统的「始终开启的 VPN」。
- **新增**：切换节点时可选择中断已有连接。
- **改进**：「更改尚未生效」提示移到配置页，应用方式更简单。
- **修复**：Provider 预取失败时仍可导入配置；放宽原始配置的 DNS 劫持检查。

## 1.2.22 · 2026-10-25 {#v1-2-22}

- **新增**：自动切换支持 **恢复切回**，原节点恢复后自动切回。
- **新增**：状态栏显示实时下载速度。
- **改进**：ROOT 模式应用规则的速度明显加快；启动时给核心最多 15 秒就绪时间。
- **修复**：离开页面后待应用的配置修改仍会生效，VPN 模式下热重载；手动同步未设置更新间隔的配置时正确保存。
- **修复**：禁用系统 IPv6 的防护只作用于应用可访问的网络。

## 1.2.21 · 2026-10-21 {#v1-2-21}

- **改进**：界面用语统一为「代理」。
- **核心**：AndroidLibClashLite 更新到 v1.19.33。

## 1.2.20 · 2026-10-20 {#v1-2-20}

- **新增**：自动切换可用节点，支持期望延迟；展示经实际流量验证正常的策略组。见 [AsteriskMETA · 自动切换](../guide/meta#auto-switch)。
- **新增**：自动隐藏导航栏设置。
- **修复**：Fake IP 地址池默认值统一，并拒绝 IPv6 地址段。

## 1.2.19 · 2026-10-18 {#v1-2-19}

- **新增**：设置中新增 **隐私** 分区，支持防截屏与隐藏桌面图标。
- **新增**：连接测试设置与 **统一延迟** 开关。
- **修复**：放宽核心与辅助进程端口就绪检测。

## 1.2.18 · 2026-10-15 {#v1-2-18}

- **新增**：用户数据备份与还原。
- **新增**：URL 配置可根据订阅标题自动命名。
- **修复**：允许不含节点或 Provider 的配置；bpf2socks 中继、热点与空闲唤醒相关问题。

## 1.2.17 · 2026-10-13 {#v1-2-17}

- **修复**：统一应用托管的 DNS 规则，并要求同时覆盖 TCP 与 UDP；增强模块的 DNS 与 netd 问题。
- **改进**：配置卡片更简洁；改进增强模块安装对话框。

## 1.2.16 · 2026-10-13 {#v1-2-16}

- **修复**：DNS 劫持只作用于代理入站；统计通知会话隔离并处理启动失败。

## 1.2.14 · 2026-10-09 {#v1-2-14}

- **修复**：服务停止时网络监测不经本地代理；ROOT 模式绕过私有地址段的范围。

## 1.2.13 · 2026-10-05 {#v1-2-13}
