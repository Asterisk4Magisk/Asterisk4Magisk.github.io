# AsteriskBOX 更新日志

这里整理了 AsteriskBOX 各正式版本中用户可感知的变化。完整的提交列表与安装包见 [AsteriskBOX Releases](https://github.com/Asterisk4Magisk/AsteriskBOX/releases)。

日期为 GitHub Releases 的发布日期（UTC）。

## 1.1.26 · 2026-11-05 {#v1-1-26}

- **新增**：协议插件。安装插件 APK 后可使用 Mieru、ShadowQUIC、Juicity 出站，也可改用插件版 Hysteria2 / NaiveProxy。见 [AsteriskBOX · 协议插件](../guide/box#plugins)。
- **新增**：Android 17 上启动时申请本地网络权限。
- **新增**：顶栏标签页布局下，选择器较多时可点击 **展开代理组** 在面板中快速跳转。
- **修复**：Mieru 分享链接改为官方 `mierus://` 格式，并修正插件出站的配置生成。

## 1.1.25 · 2026-11-03 {#v1-1-25}

- **新增**：出站分组可以分享与导出——订阅二维码、复制订阅链接、复制组内全部出站链接、导出链接到文件。见 [AsteriskBOX · 添加分组](../guide/box#添加分组)。
- **新增**：首页网络活动卡片改为点阵波形，可切换为双折线；资源监控拆分为 CPU 与内存两张卡片。
- **新增**：开机时已连接到匹配「连接 WiFi 时停止」的网络时，开机自启不再启动代理。
- **改进**：快捷设置磁贴实时反映运行状态。
- **修复**：ROOT 模式使用自定义核心时，导入、保存与启动不再被内置核心的校验拒绝。
- **修复**：默认 Mihomo Provider 获取器导致的崩溃。

## 1.1.24 · 2026-11-01 {#v1-1-24}

- **新增**：代理页支持 **展开列表** 布局。
- **改进**：VPN Service 运行在独立进程中；后台与屏幕关闭时暂停运行时数据刷新与流量统计。
- **改进**：新建的 Hysteria2 出站默认关闭 Chrome QUIC 伪装。
- **修复**：离开页面后 ROOT 服务不再被停止；asteriskd 更新到 v2.2.7，bpf2socks 更新到 v1.2.2。

## 1.1.23 · 2026-10-28 {#v1-1-23}

- **新增**：VPN Service 模式支持开机自启，并支持系统的「始终开启的 VPN」。
- **新增**：支持 Hysteria2 Realm 链接，订阅导入更完善。
- **修复**：选择器的正则过滤只匹配节点名称；恢复与 Xray 26.9.8 及以上版本的 REALITY 兼容性。
- **改进**：「修改尚未生效」提示更清晰，应用方式更简单。

## 1.1.22 · 2026-10-25 {#v1-1-22}

- **新增**：URLTest 支持按顺序 **故障转移**。
- **新增**：扫描二维码添加订阅分组；从本地配置文件创建分组；保存分组后立即拉取订阅；同步失败时可重试。
- **新增**：分组卡片显示同步时间与到期时间；出站修改需要重启服务时给出提示。
- **新增**：状态栏显示实时下载速度。
- **改进**：ROOT 模式应用规则的速度明显加快；分组配置的应用与服务控制协调，VPN 模式下热重载。
- **修复**：禁用系统 IPv6 的防护只作用于应用可访问的网络。
- **核心**：sing-box 更新到 v1.15.0-alpha.13-reF1nd。

## 1.1.21 · 2026-10-21 {#v1-1-21}

- **修复**：AAAA 查询交给 FakeIP 处理。
- **核心**：AndroidLibBoxLite 更新到 v1.15.0-alpha.11-reF1nd-android.3，默认 DNS 改为本地解析。

## 1.1.20 · 2026-10-20 {#v1-1-20}

- **新增**：路由规则的 `package_name` 条件可以直接从已安装应用中选择。
- **新增**：独立的 IPv4 FakeIP 设置，ROOT 模式下强制作用于全部应用。
- **新增**：自动隐藏导航栏设置。
- **修复**：仅在 FakeIP 生效时持久化映射。

## 1.1.19 · 2026-10-18 {#v1-1-19}

- **新增**：设置中新增 **隐私** 分区：在最近任务中隐藏、防截屏、隐藏桌面图标。
- **新增**：全局连接测试设置；延迟测试按钮显示实时进度。
- **修复**：放宽核心与辅助进程端口就绪检测。

## 1.1.18 · 2026-10-15 {#v1-1-18}

- **修复**：增强模块的 DNS 事件与重启恢复；bpf2socks 中继、热点与空闲唤醒相关问题。

## 1.1.17 · 2026-10-13 {#v1-1-17}

- **修复**：增强模块的 DNS 与 netd 问题。
- **改进**：出站分组卡片更简洁；改进增强模块安装对话框。

## 1.1.16 · 2026-10-13 {#v1-1-16}

- **新增**：集成应用列表增强与 DNS 增强（需安装增强模块）。
- **修复**：切换 DNS 与路由规则类型时清除不再使用的字段；统计通知会话隔离并处理启动失败。

## 1.1.14 · 2026-10-09 {#v1-1-14}

- **新增**：eBPF 模式绕过私有地址的开关。
- **新增**：出口公网地址探测支持双栈与经由代理；代理页可定位当前节点，导航栏随滚动显示 / 隐藏。
- **修复**：服务停止时网络监测不经本地代理；ROOT 模式绕过私有地址段的范围。
- **核心**：sing-box 更新到 v1.15.0-alpha.11-reF1nd。

## 1.1.13 · 2026-10-06 {#v1-1-13}

- **新增**：覆写脚本调试时显示配置校验警告；配置预览可复制。
- **改进**：统一的页面搜索与搜索栏动画；服务按钮移到浮动导航栏旁。
- **修复**：校验设置时不运行覆写脚本；订阅更新优先经本地代理，失败时回退直连。
- **核心**：sing-box 更新到 v1.15.0-alpha.10-reF1nd。

## 1.1.12 · 2026-09-29 {#v1-1-12}

- **新增**：出站管理菜单支持批量复制与删除。
- **修复**：订阅更新时保留出站 ID；允许导入重复的出站；策略链显示顺序；规则模式改用 `route.final`。
- **核心**：sing-box 更新到 v1.15.0-alpha.9-reF1nd。

## 1.1.11 · 2026-09-27 {#v1-1-11}

- **新增**：覆写脚本与配置预览。见 [sing-box 配置](../guide/core-singbox)。
- **新增**：分组级前置代理。
- **新增**：DNS 服务器支持可编辑的 hosts 文件；路由与 DNS 规则支持 `dns_server_address`、`dns_search_domain`。
- **新增**：轻量的自动暂停与恢复；Android 13 及以上支持锁屏 / 解锁服务控制。
- **修复**：延长 ROOT 连接重试；切换语言后界面即时更新。

## 1.1.10 · 2026-09-24 {#v1-1-10}

- **核心**：sing-box 更新到 v1.15.0-alpha.8-reF1nd。
